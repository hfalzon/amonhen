## Sandbox broker and command help

This release adds a host-side broker for sandboxed Amon Lhaw applications. A
repository can receive a time-limited project grant; the host retrieves the
configuration using its stored BWS credential and exchanges encrypted responses
through the repository. Repeated and concurrent test processes reuse the grant.

Run `amonhen broker help` for the workflow, or `amonhen broker help grant` for
options and an example. Incomplete or invalid grant commands now show the full
usage. The broker must run in a normal host terminal.

## Verification and limits

The host-to-sandbox flow was exercised on Windows with synthetic credentials and
a controlled BWS executable, including concurrent requests. One earlier request
timed out without an identified cause. Live BWS integration and macOS/Linux
runtime behaviour remain unverified. Access keys are bearer credentials: anyone
able to read a repository key can use its grant until expiry or revocation. The
broker is not a strong isolation boundary against hostile concurrent repository
path changes. See the README's sandbox broker section for details.
