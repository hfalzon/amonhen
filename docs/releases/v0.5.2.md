## Live broker activity

The broker terminal now shows each handled request with its time, success or
failure, granted repository, project and a short reason. It never prints the
access key, machine token or configuration values, and does not write a log file.
The repository shown identifies the grant, not a verified process identity.
Requests that never reach the running broker cannot appear in its terminal.

The terminal output was checked across the Windows host/sandbox boundary using
synthetic credentials and responses, including success and rejected requests.
The broker's existing security and platform limitations still apply; see the
README for details.
